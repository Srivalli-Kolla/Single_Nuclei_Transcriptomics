# Single-Nuclei Transcriptomics Analysis Template (R)

This repository serves as a **reproducible, open-source workflow** for the complete analysis of single-cell and single-nuclei RNA-sequencing (sc/snRNA-seq) data.

It contains a modular set of scripts—one for each major step—that users can adapt and apply to their own filtered count matrices. **No data files are included**, making this an agile resource focused purely on computational methodology and best practices.
